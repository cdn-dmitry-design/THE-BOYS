# THE BOYS — попапы для Тильды

Кастомные попапы сайта: заявка, подарочная карта, FAQ перед визитом и история. На страницу Тильды в блок T123 ставится одна строка из `docs/tilda-embed.html` — она подгружает скрипты с CDN (jsDelivr поверх этого репозитория).

## Как открыть

Клик по ссылке с хэшем. Лоадер сразу снимает якорь, страница остаётся на месте.

| Попап | Триггер | Форма Тильды |
|--------|---------|--------------|
| Заявка | `#order` · `#zayavka` · `data-tb-pop="order"` | `rec4168108201` |
| Подарочная карта | `#gift` · `#card` · `#podarok` · `data-tb-pop="gift"` | `rec4169596401` |
| Перед визитом | `#visit` · `data-tb-pop="visit"` | — |
| История | `#story-1` · `data-tb-pop="story"` | — |

Заявка и карта рисуют свой интерфейс, переписывают поля скрытого блока формы BF204N и жмут его Submit. Письма, CRM, вебхуки и капча уходят как у обычного блока BF204N. Если id блока другой:

```html
<div id="tbOrderMount" data-form-rec="ВАШ_REC_ID" hidden></div>
<div id="tbGiftMount" data-form-rec="ВАШ_REC_ID" hidden></div>
```

## Что оставить на Тильде

1. Стандартные формы BF204N. Попапы привязаны к ним и отправляют именно их. Прятать через CSS: если скрыть блок в Тильде, форма не уйдёт.
2. Кнопки с хэшами из таблицы.
3. Блок T123 со строкой из `docs/tilda-embed.html`.

После смены скрипта страницу нужно опубликовать заново.

## Файлы

```
cdn/                  скрипты и стили, которые грузит сайт
  popups.js           лоадер
docs/tilda-embed.html строка для блока T123
tilda-backup/         полные HTML, если вставлять попап целиком, без CDN
Попап *.html          исходники попапов
```
